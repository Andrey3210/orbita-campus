# Historial de versiones

## 0.3.0-rc.1

- Segundo entregable del Taller. Incluye la especificación, React, API REST en Spring Boot, persistencia MySQL y el flujo de seis estados.
- Autenticación con correo UNMSM verificado, BCrypt y JWT, más autorización por rol y solicitud.
- Demostración en Pages, contenedor de la API, pruebas en GitHub Actions y documentación OpenAPI.

## Hitos de desarrollo

- **Fase 1.** Alcance, historias, escenarios BDD y diseño de pantallas.
- **Fase 2.** MVP con roles, solicitudes, asignación, seguimiento y catálogos.
- **Fase 3.** Verificación institucional, seguridad, automatización y empaquetado de la versión candidata.
