# Historial de versiones

## 1.0.0

- Pruebas de aceptación en navegador, SAST, DAST y carga y estrés sobre un entorno MySQL aislado.
- Logs JSON, correlación de trazas, métricas HTTP y monitoreo de disponibilidad con alertas en Actions.
- Validación lineal del correo institucional, actualización de Vite y referencia de soporte en fallos de API.
- Manual de usuario, manual técnico y guion de sustentación.

## 0.3.0-rc.6

- Gateway HTTP con rutas públicas controladas y límite de tamaño de petición.
- Cookie para recordar la categoría filtrada en solicitudes.
- Carga de evaluación con doce usuarios y veinticuatro solicitudes con historial.
- Prototipo actualizado y evidencias de las fases I a III.

## 0.3.0-rc.5

- Autoriza explícitamente el origen de GitHub Pages en la conexión con la API.

## 0.3.0-rc.4

- Configuración de despliegue de la API con MySQL en Railway y comprobación de disponibilidad desde GitHub Pages.
- Envío opcional de enlaces de cuenta por HTTPS y aprovisionamiento de los cuatro perfiles mediante secretos del servidor.

## 0.3.0-rc.3

- Acceso y permisos gestionados por la API en todo el portal.
- Aprovisionamiento local de una cuenta de prueba por rol con contraseñas independientes.
- Informe con capturas del entorno integrado con MySQL.

## 0.3.0-rc.2

- Portada de acceso institucional, paleta azul y fotografías referenciales de espacios universitarios.
- Registro, confirmación del correo con contraseña de registro, reenvío y recuperación con enlaces de un solo uso.
- Cambio de contraseña en el perfil y revocación de sesiones al actualizar la clave.
- Demostración por rol desde la portada e informe con las pantallas de la versión.

## 0.3.0-rc.1

- Segundo entregable del Taller. Incluye la especificación, React, API REST en Spring Boot, persistencia MySQL y el flujo de seis estados.
- Autenticación con correo UNMSM verificado, BCrypt y JWT, más autorización por rol y solicitud.
- Demostración en Pages, contenedor de la API, pruebas en GitHub Actions y documentación OpenAPI.

## Hitos de desarrollo

- **Fase 1.** Alcance, historias, escenarios BDD y diseño de pantallas.
- **Fase 2.** MVP con roles, solicitudes, asignación, seguimiento y catálogos.
- **Fase 3.** Verificación institucional, seguridad, automatización y empaquetado de la versión candidata.
