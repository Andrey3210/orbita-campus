# Demostración para la sustentación · Grupo 7

Duración sugerida de 8 a 10 minutos. Usa [Órbita Campus](https://andrey3210.github.io/orbita-campus/) y las cuentas privadas del grupo. Prepara una solicitud con un asunto único y evita mostrar el archivo de contraseñas. Si la API pública está indisponible, ejecuta el entorno local del manual técnico con MySQL aislado.

| Tiempo | Demostración | Evidencia en pantalla |
| --- | --- | --- |
| 0:00–1:00 | Explicar el problema y abrir la portada UNMSM. | Un dominio ajeno se rechaza y una cuenta de evaluación inicia sesión. |
| 1:00–2:30 | Crear un pedido de soporte como estudiante. | Código, categoría, ubicación, descripción y estado Registrada. |
| 2:30–4:00 | Evaluar, priorizar y asignar como supervisor. | Cambio de plazo, responsable y eventos en la ficha. |
| 4:00–5:30 | Atender, comentar y resolver como técnico. | El pedido asignado y la evidencia de la solución. |
| 5:30–6:30 | Cerrar como supervisor y consultar el tablero. | Historial completo y recuentos por estado. |
| 6:30–7:20 | Abrir el catálogo como administrador. | Gestión de áreas y categorías. |
| 7:20–9:00 | Mostrar release, calidad y observabilidad. | Ejecución en Actions, mediciones de carga, salud y una traza sin datos personales. |

## Validación con usuarios del grupo

Completa el [registro de validación con usuarios](validacion-usuarios.md) con lo que observó el grupo. Para repetir un fallo, conserva el estado, el paso y la referencia de soporte. El recorrido de Playwright documenta la aceptación automatizada.
